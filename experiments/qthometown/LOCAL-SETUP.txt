This demo uses the proprietary DeepAR SDK, not a standalone open-source CNN tracker. The repository's application code carries an MIT license (included as LICENSE). Do not assume that license covers the SDK service or third-party branded effects.

Local changes:
- Removed the repository author's hard-coded DeepAR license key.
- Read your own key from the DEEPAR_LICENSE_KEY environment variable.
- Pin DeepAR to 5.6.2: DeepAR's support team reports foot tracking was deprecated in newer versions.
- Default to the included Nike Dunk effect.
- Add initialization error handling and a missing-key message.
- Serve HTTPS on all interfaces for phone testing, port 8888.

Run from this directory:
  npm install
  DEEPAR_LICENSE_KEY='YOUR_OWN_WEB_APP_KEY' npm run dev

Open https://localhost:8888/tryon.html on the laptop. For a phone, use the laptop's current LAN IP and port 8888 over HTTPS. The key must be valid for the test environment/domain; follow DeepAR's license configuration instructions. Do not commit your key or send it in chat. A legacy SDK key/license may need confirmation from DeepAR support.

Without a key, the page displays setup instructions and deliberately does not initialize tracking. A successful build is not a measurement of tracking accuracy. Compare both feet, single foot, rotation, crossings, tracking loss, and reacquisition on the actual phone before selecting this as the replacement tracker.

The shoe assets here are packaged .deepar effects. SOLE AR GLB files cannot simply be substituted: they need authoring/export through the appropriate DeepAR effect workflow.
